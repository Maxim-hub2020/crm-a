# CRM Development Tasks

Here is a list of tasks based on user feedback to improve the CRM system.

## General Improvements
- [ ] **Clickable Dashboard:** Make all items on the dashboard (like tasks and projects) clickable, linking to their respective details pages.

## Finance Module
- [ ] **Transaction Account Validation:** When creating an income or expense, the "Account" field should be mandatory. There should be no "account category without an account".
- [ ] **Finance Filter:** Implement a filtering system for financial data. Users should be able to filter by date, category, and account.

## Mobile Responsiveness & UX
- [ ] **Fix Screen Fit Issues:** Investigate and fix responsive design issues on mobile devices, specifically on iPhone 15 Pro, to avoid the need for zooming.
- [ ] **Project Card on Mobile:** On the mobile version, the project card should display or provide access to finances, comments, and tasks associated with the project.
- [ ] **Improved Mobile Search:** Redesign the mobile search functionality. Instead of displaying results in columns, show them in a list format for better usability and to avoid horizontal scrolling.
